# 墨读 Inkstone

一个离线、跨平台的 Markdown 阅读与批注桌面应用。原文件保持不变，高亮、加粗、书签和图片批注独立保存在本机。

## 直接使用（macOS Apple Silicon）

解压 `release/Inkstone-0.1.1-arm64-mac.zip`，打开 `Inkstone.app`，也可以将其拖入“应用程序”。这是个人使用的未公证开发版本；若 macOS 拦截，右键应用选择“打开”，或在系统设置 → 隐私与安全性中确认打开。

点击“打开文件”或“打开文件夹”，或把 `.md` / `.markdown` 文件拖入窗口。文件夹树保留现有目录结构，最近阅读列表记录已经打开的文件。

## 标记与批注

选中正文后使用浮动工具条或快捷键：

| 操作 | Mac | Windows |
| --- | --- | --- |
| 高亮／取消同一选区高亮 | ⌘⇧H | Ctrl+Shift+H |
| 加粗／取消同一选区加粗 | ⌘B | Ctrl+B |
| 新建批注 | ⌘⇧M | Ctrl+Shift+M |
| 文内搜索 | ⌘F | Ctrl+F |
| 打开文件 | ⌘O | Ctrl+O |
| 打开文件夹 | ⌘⇧O | Ctrl+Shift+O |
| 专注模式 | ⌘⇧F | Ctrl+Shift+F |

**自定义快捷键（0.1.1）**：点击右上角“阅读设置” → “快捷键”，点击高亮、加粗或批注右侧的按键，再按下新的组合。支持单键（例如 H 高亮、N 批注），也支持搭配 ⌘ / Ctrl、Shift、Option / Alt。修改即时保存，重启仍生效；冲突会显示提示，可恢复默认。输入笔记时不会触发标记。

高亮有四种颜色，加粗和批注可以与高亮叠加。标记快捷键只对正文中的有效选区生效，不处理正在编辑的输入框。原始 Markdown 内容不会被修改。

批注中可写文字、粘贴截图、拖入图片，或点击“添加图片”。支持 PNG、JPEG、WebP，单张不超过 20 MiB。支持多张图片和纯图片批注。图片导入完成后复制到应用数据目录；可点开大图或单独删除。图片导入期间关闭批注会取消该次关联。空批注草稿关闭后自动丢弃。

## 阅读与文件变化

- GFM 表格、代码高亮、KaTeX 数学公式、Mermaid、脚注与本地相对路径图片。
- 左侧目录、文内搜索、书签、阅读进度恢复；浅色、暖纸、夜读主题及字号／行距／宽度调节。
- 监听外部文件修改：正文更新后重新定位标记。无法可靠匹配的标记显示“待定位”；点击“关联”，重新选择正文，再点“关联此处”。
- 文件移动／删除后，保留全部笔记，使用“重新关联文件”找回原文。不按文件名猜测文件身份。
- 公式与图表内部不支持文字标记；它们不会进入正文标记文本索引。
- 为保持响应，单篇文档限制 30 MiB，文件夹遍历深度限制 12 层，跳过隐藏目录、符号链接与 node_modules。
- 原始 HTML 不执行。网页链接交给系统浏览器；远程图片需点击主动加载。图片格式验证失败时显示错误。

## 导出、备份与数据位置

右上角更多菜单提供“导出当前笔记”“完整备份”“恢复备份”。

- 无图片的笔记导出为 Markdown；含图片则导出 ZIP，内有 `notes.md` 和 `assets/`。
- 完整备份 ZIP 含版本化 JSON、全部标记、文档记录、阅读位置、书签及关联图片；**不包含原 MD 文件及其正文图片**，原文件需另行备份。
- 恢复按文档／标记 ID 去重，已有记录优先保留。文档路径与已有不同身份记录冲突时，导入记录使用缺失路径标识，之后可手动重新关联。主题偏好保留当前设备设置。
- 数据目录由 Electron 的 `userData` 决定：macOS 通常在 `~/Library/Application Support/Inkstone/`（开发模式为 `inkstone-reader`），Windows 在 `%APPDATA%/Inkstone/`。数据库为 `reader.sqlite`，图片在 `assets/`。
- 已删批注的未引用图片暂不自动清理；完整备份只打包仍被引用的图片。

## 开发与构建

使用 Node.js 24 或更新版本。Electron 内置 Node 的 SQLite，无需原生 SQLite 模块编译。

```sh
npm ci
npm run dev
```

```sh
npm test                 # 定位、DOM 标记、SQLite、图片与备份测试
npm run build            # TypeScript 检查与生产构建
npm run test:e2e         # 启动真实 Electron 窗口测试交互
npm run dist:mac         # 构建当前 Mac 架构的 ZIP
npm run dist:win         # 在 Windows 构建 NSIS 安装程序
```

若 Electron 运行时下载失败，可按所在网络设置 `ELECTRON_MIRROR` 后重新运行 Electron 安装脚本。构建默认不提供发布签名、公证或自动更新；Windows 签名证书需自行配置。

## 源码结构

- `electron/index.ts`：窗口、受限 IPC、文件授权、监听、菜单与图片读取。
- `electron/store.ts`：SQLite、图片资源校验、导出和事务恢复。
- `electron/preload/`：类型化桥接，不暴露任意 IPC 或 Node 能力。
- `src/App.tsx`：文件／阅读／笔记三栏及操作状态。
- `src/anchors.ts`、`src/marks.ts`：正文文本索引、版本指纹、上下文定位和重叠标记。
- `src/Markdown.tsx`、`src/NoteEditor.tsx`：文档渲染与图片笔记。

验证详情见 `docs/VALIDATION.md`。Windows 和 Intel Mac 尚未实机验证，不视作已验证兼容平台。

### 0.1.2：点击原文查看批注

点击正文带下划线的文字，右侧自动打开并滚动到对应批注，目标卡片会突出显示。需要修改时点击卡片上的“编辑”。若同一文字关联多条批注，会先显示选择列表。筛选隐藏目标时自动切换为“全部”，专注模式下会退出专注显示批注。

### 0.1.3：四色高亮快捷键

默认 H 黄色、J 绿色、K 蓝色、L 粉色；选中正文后按键即可高亮。不同颜色覆盖选区，选区全部为相同颜色时再次按键取消；选区外不变。原高亮快捷键使用最近颜色。阅读设置 → 快捷键可修改或清除各颜色绑定。升级保留已有设置；若默认颜色键被已有快捷键占用，该颜色显示“未设置”，请手动绑定。导出的 Markdown 笔记以中文颜色名称标注高亮。

### 0.1.4：隐藏右侧高亮记录

右侧默认隐藏高亮记录，保留批注与加粗记录。开启右侧“显示高亮记录”可查看全部高亮；开关会自动保存，重启仍有效。隐藏只影响侧栏展示，正文颜色、保存、导出和备份不受影响。
